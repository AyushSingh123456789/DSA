public class ArrayToMethod{
    public static void main(String[]args){
        int[] x = {10,3,29,6};
        System.out.println(x[2]); // Prints 29
        change(x);
        System.out.println(x[2]); // Prints 99
    }
    public static void change(int[] y){
        y[2] = 99;
    }
}

Note: Both 'x' and 'y' are not the Name of Variables, rather 'x' and 'y' are the Reference of the same integer Array. And, That's why the change inside the array is possible through any among the two references, 
e.g: First SOP(x[2]) => prints 29 assigned initially.
Then change(x) method is called, and through the reference 'y', the y[2] element is changed to 99, Finally, SOP(x[2])=> prints 99 assigned inside the change method through the variable 'y'.


Imp Note: Whenever we pass an Array through Methods, then the Array is passed through Reference.
